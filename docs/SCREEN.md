# Pantalla

La captura requiere consentimiento explícito, se mantiene en memoria y registra solo dimensiones/hash, nunca la imagen. Se reduce a un lado largo configurable (1280 px por defecto). El OCR produce cajas validadas; un modelo de visión es opcional y se carga bajo demanda. La captura real, OCR Tesseract y la ventana overlay transparente requieren pruebas manuales en Windows.
